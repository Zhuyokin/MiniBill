# MiniBill 视觉系统

## 1. 视觉方向

关键词：微信式克制、Apple 原生、轻拟物品牌、内容优先、可信赖。

界面本身保持扁平和安静；拟物感只集中在 App Icon，不扩散到按钮、卡片或图表。这样既保留品牌识别，又不会破坏日常记账效率。

## 2. 色彩

| Token | 浅色模式 | 用途 |
|---|---:|---|
| Brand Green | `#07C160` | 主要操作、收入、选中状态 |
| Brand Green Dark | `#079447` | 浅底文字和小图标 |
| Brand Green Soft | `#E9F8EF` | 项目首字标记、弱选中背景 |
| Background | `#F5F5F5` | 页面背景 |
| Surface | `#FFFFFF` | 卡片、列表、面板 |
| Ink | `#191919` | 主文字、支出金额 |
| Muted | `#858585` | 次要信息 |
| Divider | `#EDEDED` | 1 px 分隔线 |
| Destructive | `#D94235` | 删除、覆盖恢复 |

规则：

- 品牌绿只用于一个页面的主操作或明确的收入语义。
- 支出不使用大面积红色，使用负号与中性深色；红色只保留给破坏性操作。
- 收入和支出必须有文字或正负号，不依赖颜色。
- 深色模式使用系统动态色映射，保持相同语义层级。

## 3. 字体与数字

- 使用系统字体：SF Pro / PingFang SC 及对应地区系统字体。
- 页面标题 17–20 pt，Semibold。
- 大金额 28–32 pt，Bold，使用 tabular figures。
- 列表正文 15–17 pt；说明文字不低于 12 pt。
- 金额统一保留两位小数的输入能力；展示时允许省略无意义小数，但同一区块格式一致。
- 不使用全大写英文标题，不使用装饰字体。

## 4. 间距与圆角

基础间距：4、8、12、16、24、32 pt。

| 组件 | 圆角 |
|---|---:|
| 按钮 / 输入框 | 10–12 pt |
| 内容卡片 | 14–16 pt |
| 底部快速面板 | 顶部 24–26 pt |
| 悬浮记账按钮 | 圆形 54–56 pt |
| App Icon 预览 | 由 iOS 系统遮罩 |

列表内优先使用分隔线，不给每一行单独套卡片。阴影只用于悬浮按钮、底部面板和恢复确认层。

## 5. 核心组件

### 本月汇总卡

月份位于顶部；净收益为第一视觉焦点；收入和支出并列放在下方。整卡可点击进入统计，不在卡内放多个按钮。

### 流水行

左侧是项目名称首字标记，不是分类图标。中间为项目名称与时间/备注；右侧为金额。备注最多一行并截断。

### 快速记账面板

收入/支出分段控件、金额、项目名称、历史候选、可选字段、数字键盘。保存按钮与数字键盘同区，单手可达。

### 项目排行

使用单色水平条；收入为品牌绿，支出为中性深色。排行项展示项目名称和金额，不展示百分比饼图。

### 设置列表

采用微信式分组列表；说明放在组下方，避免额外帮助按钮。

## 6. App Icon

推荐稿：`assets/app-icon-recommended-1024.png`。

构图：全幅绿色底、象牙白微立体账本、准确的 `¥` 符号和一支小型记账笔。材质是软质纸张/珐琅式微拟物，不使用前两版的写实皮革。

约束：

- 1024×1024 PNG，无 Alpha。
- 不预先裁切 iOS 圆角。
- 不含 MiniBill 文字、数字或复杂图表。
- 在 60 px 下仍能辨认账本、人民币和笔。
- 不模仿微信气泡或微信 Logo。

## 7. 分享图

月度收益图：3:4，逻辑画布 900×1200。白色背景、固定边距、品牌锁定区、核心数字、简化趋势和 TOP 项目。

单笔流水图：同样使用白底与品牌锁定区，重点展示项目名称和金额。

分享图始终使用浅色固定主题，避免接收方因深色模式得到黑底图片。App 内界面仍跟随系统明暗模式。

## 8. 多语言与自适应

- 控件不得为中文固定宽度。
- 英语、日语、韩语按钮允许换行或扩展高度。
- 繁中采用人工校对术语。
- 金额、日期和时间使用地区格式，不在图片上硬编码中文单位。
- 最大动态字体下，主操作和金额优先完整显示；次要说明可换行。
